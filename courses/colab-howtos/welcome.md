# Colab how-tos

Practical how-tos from [The Colab](https://thecolab.ai), a community of people in Aotearoa New Zealand building with AI.

Each week we write a recap of the techniques people shared in the community. Each technique becomes an open issue, and a community member picks it up, works through it and writes it up as a module in this course.

## Where the modules come from

Modules arrive from contributors. Anyone can claim an open issue labelled `module` and `help wanted`, build the module and open a pull request. See [CONTRIBUTING.md](https://github.com/thecolab-ai/colab-howtos/blob/main/CONTRIBUTING.md) for how.

The `example-howto` module shows the layout. It is hidden on the site and is never published.

## Status

Each module has a status:

- **seed**: an outline from the recap. Nobody has run the steps yet.
- **draft**: written up and partly worked through. Untested steps are marked.
- **tested**: a contributor ran every step, on the date given in the module's Notes.

Guides describe community experience, not official vendor advice. Check the linked docs and use at your own risk.
